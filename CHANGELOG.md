# Changelog

Версионирование: [SemVer](https://semver.org/lang/ru/).
**major** — ломающие изменения контрактов, на которые опираются downstream-форки
(claims SSO-JWT, схема `POST /api/v1/events`, формат исходящих вебхуков,
несовместимые изменения схемы БД). **minor** — новые возможности без слома.
**patch** — исправления.

## 0.2.0 — 2026-07-29
- Рабочие разделы: канбан лидов с drag&drop, клиенты с поиском, задачи с чек-оффом, календарь с модалкой дня, отчёты, живой дашборд
- CRUD-настройки: роли с матрицей прав, филиалы, webhook-эндпоинты; гейты прав по разделам и скоуп по филиалам
- Локаль ru по умолчанию (rails-i18n), словари разделов/действий/статусов
- Дизайн-система v2: графитовый сайдбар + кобальт, Rubik / Nunito Sans, анимации с учётом reduced-motion

## 0.1.0 — 2026-07-28
- Каркас ядра: аутентификация (пароль + generic SSO), роли/membership/филиалы, идемпотентный inbox и outbox-вебхуки, Docker-окружения dev и prod
